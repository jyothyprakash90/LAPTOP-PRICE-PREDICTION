# Laptop Price Prediction Using Machine Learning

This project predicts laptop prices based on specifications such as brand, RAM, processor, and storage using Linear Regression and Random Forest models.

## Files
- LAPTOP_PRICE_DATA_ANALYSIS.ipynb : Data analysis and model training
- app.py : Flask web application
- laptop_price_linear_model.pkl : Trained ML model
- requirements.txt : Required libraries

## How to Run the App
1. Install libraries:
   pip install -r requirements.txt
2. Run the Flask application:
   python app.py

## Model Performance
- R2 Score: 0.99
- MAE: ~150
- RMSE: ~190
